Mode d'emploi

🔢

Calculatrice

Chiffres, + − × ÷, parenthèses ( ) et % fonctionnent comme une calculatrice classique.

Δ%

Variation en %

Tapez un nombre, appuyez sur Δ% — il devient "de", le clavier se simplifie et = devient Δ=. Tapez le second nombre ("à"). Touchez les rectangles "de" ou "à" pour basculer entre les deux et corriger si besoin. Appuyez sur Δ= pour valider et enregistrer.

💶

TVA+ / TVA-

Ajoute ou retire la TVA sur le montant affiché. Le taux se règle juste au-dessus, dans ces paramètres.

🕘

Historique

Appui court sur une ligne : renvoie le résultat dans la saisie.
Appui long : copie le résultat.
Double-clic sur C : efface tout l'historique (avec confirmation).

🎨

Thème

Clair, Sombre, ou Système (suit automatiquement le réglage de votre iPhone).

Effacer l'historique ?

Cette action supprimera définitivement tout l'historique des calculs enregistrés sur cet appareil.
